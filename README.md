# Advent of Code 2021

My solutions to [Advent of Code 2021](https://adventofcode.com/2021), the yearly December run of daily programming puzzles. I do it as a fun warm-up exercise, usually until the puzzles start eating my evenings.

**Language:** JavaScript (Node.js)
**Progress:** Days 1–14

## Layout

One file per day, `1.js` through `14.js`. Each file is self-contained: the puzzle input (and usually the example from the puzzle description) is pasted in as a string, and the script solves both parts and prints the answers.

## Running

```bash
node 1.js
```
